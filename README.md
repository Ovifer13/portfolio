# Personal Portfolio | Frontend Engineer

This is my professional portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS** and **shadcn/ui**. It serves as a central hub to showcase my 4+ years of experience in the software industry, featuring projects developed for international companies.

## 🚀 Tech Stack

*   **Framework:** [Next.js](https://nextjs.org/) (App Router).
*   **Language:** [TypeScript](https://www.typescriptlang.org/) for type-safe development.
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/).
*   **Deployment:** [Vercel](https://vercel.com/).

## ✨ Key Features

*   **Responsive Design:** Optimized for all devices, from mobile to ultra-wide monitors.
*   **Performance:** High Lighthouse scores by leveraging Next.js Image optimization and static site generation (SSG).
*   **Case Studies:** Detailed technical breakdowns of my work at **Compass Mining**, **OnPoint Insurance**, and **The SetLife Network**.
*   **Dark Mode:** Built-in support for a seamless visual experience.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-user/portfolio.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
